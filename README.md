# موقع مؤسسة عابدين — النسخة النهائية V9

## التشغيل
افتح `index.html` مباشرة، أو شغّل المجلد عبر خادم ويب محلي.

## أبرز التحسينات
- أيقونة احترافية وواضحة لزر طلب عرض السعر.
- توافق كامل مع الهاتف والتابلت واللابتوب.
- صور المنتجات الزراعية الحقيقية.
- تحسين الوصول عبر لوحة المفاتيح ورابط تخطي المحتوى.
- إزالة الروابط الاجتماعية الوهمية مع الإبقاء على الأيقونات لحين إضافة الروابط الرسمية.
- تحسينات نهائية للمسافات، الحركات، وضوح الصور، وحالات التركيز.

## بيانات تحتاج تأكيدًا قبل النشر
- روابط فيسبوك وإنستغرام الرسمية.
- العنوان التفصيلي وساعات العمل.
